# ML-RAIL: Training-Free Continual Learning for CLIP

Work in progress. An X-TAIL harness (CLIP ViT-B/16, ten domains learned in sequence), a replication of
RAIL (NeurIPS 2024), and ML-RAIL: RAIL's closed-form kernel ridge adapter on multi-layer frozen features. Adds an analysis of the zero-shot gate and a
per-domain conformal rescue gate.
